# What's New: September 2026

## A Live Recording Indicator for Windows

`here` now has a Qt presentation layer and a small live-logo overlay that can stay
visible while the main window is hidden. The overlay reacts to one combined audio
level during recording, becomes static while paused, shows indeterminate processing,
and ends with clear success, error, or recoverable-cancellation feedback. A
destructively cancelled recording disappears without being presented as an outcome.

The indicator is transparent, frameless, always on top, and draggable for the
current session. A primary click restores the application. Its context menu exposes
only actions valid for the current state, and destructive recording cancellation is
clearly separated from recoverable processing cancellation.

The visual work is isolated from capture and transcription behind the shared
application contract. This means the UI can be tested headlessly with synthetic
events and cannot compromise audio recovery by opening devices or creating a
parallel processing path.
